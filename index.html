🔄 同步最新数据（Network 抓包法）

⚠️ 核心要点：请务必在 Response (响应) 标签下复制，不要在 Preview 标签下复制！

  1. 在且慢官网按 F12，点击顶部的 Network (网络) 标签。
  2. 在过滤框输入 plan，然后 刷新页面 (F5)。
  3. 找到 plan?prodCode=LONG_WIN 请求并点击，在右侧 Response 标签中 Ctrl+A 全选、Ctrl+C 复制，粘贴到下方框1。
  4. 同理，将 plan?prodCode=LONG_WIN_S 的 Response 内容粘贴到下方框2。
  5. 点击【解析并应用数据】。若官方有新增基金，将自动并入列表并提示。
